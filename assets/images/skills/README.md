# Fontes dos logos

Os nomes e marcas pertencem aos respectivos projetos e empresas.

- Java, JavaScript, Python, Godot, HTML5, CSS3, Git, GitHub, Figma, Canva, Photoshop, Blender e Premiere: SVGs da coleção [Devicon](https://github.com/devicons/devicon), variantes original. Licença MIT em LICENSE-devicon.txt.
- Aseprite, Affinity e DaVinci Resolve: [Simple Icons v15](https://github.com/simple-icons/simple-icons/tree/15.0.0/icons). Licença da coleção em LICENSE-simple-icons.txt. Exibidos em branco para contraste.
- Krita: ícone do [site oficial](https://krita.org/images/favicon.ico).
- Crocotile 3D: [favicon do site oficial](https://www.crocotile3d.com/favicon.ico).
- CapCut: favicon referenciado no [site oficial](https://www.capcut.com/), servido em https://sf16-web-tos-buz.capcutstatic.com/obj/capcut-web-buz-sg/common/images/lv_web-2.ico.

GDScript usa o logo do Godot. HTML, CSS, Git e GitHub aparecem como itens separados, cada um na sua corda. Todos os arquivos são locais, sem carregamento de terceiros durante a visita.
